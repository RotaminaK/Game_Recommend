# 🎮 게임 취향 분석기


게임에 별점을 남기면 취향이 비슷한 사용자 10명을 찾고, 그 사용자들이 높게 평가한 게임을 최대 3개 추천하는 Streamlit 앱입니다.

**Hugging Face에서 가져온 Metacritic 사용자 리뷰·평점 데이터를 기반으로 추천합니다.** 내가 입력한 별점과 기존 사용자들의 평가를 비교해 예상 별점을 계산하며, OpenAI API 키를 입력하면 게임별 추천 이유와 이미지가 없는 게임의 대체 이미지를 생성합니다.

## 제작 배경

영화는 별점을 남기면 취향을 분석하고 예상 평점을 알려주는 서비스를 쉽게 접할 수 있습니다. 반면 국내에서 게임을 대상으로 비슷한 서비스를 찾기는 어려웠고, 이 경험에서 게임 취향 분석기를 만들게 되었습니다.

전체 평균 평점이나 인기 순위만으로는 내가 그 게임을 좋아할지 판단하기 어렵다고 생각했습니다. 그래서 **나와 취향이 비슷한 사용자들이 실제로 남긴 평가**를 바탕으로, 다음에 플레이할 게임을 고르는 데 도움을 주는 것을 목표로 삼았습니다.

## 주요 기능

- **별 클릭 평가:** 가운데 별을 클릭하면 0.5~5점을 반 점 단위로 즉시 저장하고 다음 게임으로 넘어갑니다.
- **리뷰 수 기반 평가 순서:** 실제 추천에 사용하는 데이터에서 리뷰가 많은 게임부터 표시합니다.
- **미플레이 게임 넘기기:** `아직 안해봤어요`를 누르면 평점을 저장하지 않고 다음 게임으로 넘어갑니다.
- **추가 평가:** 5개 이상 평가하면 추천받을 수 있으며, 이후에도 평가를 계속 추가할 수 있습니다.
- **추천 근거 표시:** 추천 게임별 유사 사용자 평균 별점과 평가 인원을 보여줍니다.
- **GPT 추천 이유:** 입력 평점과 추천 게임의 리뷰를 참고해 한국어 한 문장으로 설명합니다.
- **이미지 처리:** 외부 게임 이미지를 먼저 검색하고, 없으면 API 키를 사용해 대체 이미지를 생성합니다.

## 추천 방식

추천의 기준은 **사용자들이 남긴 게임별 평점**입니다. 내가 입력한 별점과 기존 사용자들의 평점 패턴을 비교하는 사용자 기반 협업 필터링으로 추천 순위와 예상 별점을 계산합니다. `gpt-4o-mini`는 선정된 게임의 리뷰를 참고해 추천 이유를 설명합니다.

1. 동일 사용자가 같은 게임에 남긴 여러 평점은 평균으로 집계합니다.
2. 입력 평가 수에 따라 필요한 공통 평가 수를 늘립니다. 평가 5~10개는 공통 2개, 11~15개는 3개, 16~20개는 4개, 21개 이상은 5개를 기준으로 합니다. 대상 사용자가 10명 미만이면 공통 평가 기준을 최소 2개까지 단계적으로 낮춥니다.
3. 공통 게임의 평점 차이와 공통 평가 수로 가까운 사용자 **최대 50명**을 먼저 찾습니다. 기존 상위 10명의 거리 범위에서 0.25점 이내인 후보 중, 내가 아직 평가하지 않은 게임 리뷰가 많은 사용자에게 최대 0.25점 미만의 가점을 줘 최종 **10명**을 고릅니다. 리뷰 수만으로 취향 차이가 큰 사용자가 선택되는 것을 제한합니다.
4. 내가 이미 평가한 게임을 제외합니다.
5. 선택한 10명 중 **최소 3명이 평가한 게임**만 남깁니다.
6. 이 사용자들의 **단순 평균 평점이 높은 순서**로 최대 3개를 추천합니다. 평균이 같으면 평가 인원이 많은 게임을 우선합니다.
7. 3개에 못 미치면 같은 이웃 10명의 나머지 미평가 게임을 **평가 인원이 많은 순서**로 보충합니다. 인원이 같으면 평균 평점이 높은 게임을 우선하며, 예상 별점은 해당 게임을 평가한 이웃의 단순 평균입니다.

결과는 **취향 맞춤 추천**과 **비슷한 취향의 인기작**으로 나눠 표시하며, 두 묶음을 합쳐 최대 3개를 추천합니다. 맞춤 추천이 3개면 인기작 묶음은 표시하지 않습니다. 실제 플레이 횟수 데이터는 없으므로, 인기작의 기준은 선택한 이웃 중 해당 게임을 평가한 사용자 수입니다.

사용자 거리 계산식은 다음과 같습니다. 값이 작을수록 우선 선택합니다.

```text
거리 = 공통 게임 평점 차이의 RMSE + 1 / 공통 평가 게임 수
```

**이웃 10명이 평가한 미평가 게임 자체가 3개 미만이면 가능한 게임만 표시합니다.** 추천 가능한 게임이 없거나 공통 평가 조건을 충족하는 사용자가 10명 미만이면 안내 메시지가 나옵니다. 새 평점을 저장하면 이전 추천을 지우며, 다시 추천받을 때 최신 평점을 사용합니다.

표시되는 별점은 선택한 이웃 중 해당 게임을 평가한 사람들의 평균이며, 개인의 실제 만족도를 보장하는 점수는 아닙니다.

## 데이터

게임 리뷰와 평점은 **Hugging Face에 공개된 Metacritic 리뷰 데이터셋**에서 가져왔습니다. 실행 시 Hugging Face의 원본 Parquet 파일을 내려받아 추천 계산과 리뷰 기반 설명에 활용합니다.

- 데이터 제공 경로: **Hugging Face Datasets**
- 데이터셋: [Wada1/Metacritic_Games_Reviews_Dataset](https://huggingface.co/datasets/Wada1/Metacritic_Games_Reviews_Dataset)
- 원본 파일: `data/train-00000-of-00001.parquet`
- 주요 열: `Author`, `Game`, `Score`, `Review`
- 원본의 10점 척도를 2로 나눠 5점 척도로 사용합니다.

앱은 저장소 내 `data/train-00000-of-00001.parquet` 파일을 먼저 읽습니다. 파일이 없으면 Hugging Face에서 다운로드하고 해당 위치에 저장합니다. **첫 실행에는 인터넷 연결과 다운로드 시간이 필요합니다.**

원본을 읽지 못하면 프로젝트 폴더의 `metacritic_reviews_1.csv`~`metacritic_reviews_3.csv` 중 존재하는 파일을 대신 읽습니다. 이 CSV들은 원본 Parquet과 다른 데이터이므로 게임 목록과 추천 결과가 달라질 수 있으며, 대체 데이터 사용 여부를 화면에 표시합니다.

`metacritic_games_master.csv`, `metacritic_games_four.csv`는 현재 앱 실행에 사용하지 않습니다. 데이터 재배포 시에는 원본 데이터의 라이선스와 이용 조건을 확인해 주세요.

## 향후 계획

다음 기능은 추가할 예정이며, 현재 버전에는 구현되어 있지 않습니다.

- **하고 싶어요:** 아직 플레이하지 않았지만 관심 있는 게임을 저장하는 기능입니다. 실제 플레이 후 남긴 별점과 구분해 관리하고, 추천 이유를 개인화하는 보조 정보로 활용할 계획입니다.
- **취향 분석 리포트:** 사용자가 남긴 평가를 게임의 장르 등과 연결해 좋아하는 장르와 선호 경향을 보여주는 기능입니다. 필요한 게임 메타데이터를 보완해, 평가가 쌓일수록 자신의 취향을 살펴볼 수 있도록 만들 예정입니다.

## 설치 및 실행

Python과 `pip`가 필요하며, 아래 복제 명령을 사용하려면 Git도 설치되어 있어야 합니다. 이미 저장소를 내려받았다면 `git clone`과 `cd`를 생략하고 **이 README와 `requirements.txt`가 있는 `Game_Recommend` 폴더**에서 가상환경 생성부터 진행하세요. Python 코드만 직접 실행하거나 노트북에서 실행하지 말고 Streamlit으로 실행하세요.

### Windows · PowerShell

```powershell
# 저장소 복제 및 이동
git clone https://github.com/RotaminaK/Game_Recommend.git
cd Game_Recommend

# 가상환경 생성
python -m venv .venv

# 의존성 설치
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 앱 실행
.\.venv\Scripts\python.exe -m streamlit run game_taste_analyzer.py
```

### macOS / Linux

```bash
git clone https://github.com/RotaminaK/Game_Recommend.git
cd Game_Recommend

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run game_taste_analyzer.py
```

터미널에 표시되는 `Local URL`을 브라우저에서 엽니다. 기본 주소는 `http://localhost:8501`이며, 포트가 사용 중이면 달라질 수 있습니다. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

## 사용 방법

1. GPT 기능을 사용하려면 상단에 본인의 OpenAI API 키를 입력하고 **API 키 적용**을 누릅니다.
2. 게임 이미지와 제목을 확인하고 별을 클릭합니다. 별의 왼쪽은 반 점, 오른쪽은 한 점이며 클릭 즉시 저장하고 다음 게임으로 이동합니다.
3. 플레이하지 않았다면 가운데 **아직 안해봤어요**를 눌러 평가 없이 다음 게임으로 이동합니다.
4. 게임 5개 이상을 평가하면 **내 취향으로 3개 추천받기**를 누를 수 있습니다.
5. 평가를 추가한 뒤 다시 추천받아 결과를 갱신할 수 있습니다. **처음부터**는 평가와 추천을 초기화합니다.

### OpenAI API 키

| 기능 | API 키 필요 여부 |
| --- | --- |
| 게임 평가 및 유사 사용자 기반 추천 | 필요 없음 |
| 외부 게임 이미지 검색 | 필요 없음 |
| `gpt-4o-mini` 추천 이유 생성 | 필요 |
| `gpt-image-1-mini` 대체 이미지 생성 | 필요 |

API 키는 현재 사용자 세션에 보관하며 `.env`나 코드에 고정한 키를 사용하지 않습니다. **API 키 적용됨**은 입력한 키가 적용됐다는 뜻으로, 유효성과 모델 접근 권한은 실제 API 요청 시 확인합니다. 키를 지우고 다시 적용하면 사용을 해제합니다.

텍스트·이미지 생성 비용은 입력한 키의 OpenAI API 계정에 청구됩니다. 이미지 생성에는 추가 시간이 걸릴 수 있으며, API 사용 권한·잔액·모델 제공 여부에 따라 실패할 수 있습니다.

### 이미지와 로딩 표시

Steam 이미지를 우선 사용하고, 없으면 Wikimedia Commons와 Wikipedia에서 제목에 맞는 표지를 찾습니다. 외부 이미지를 찾지 못했을 때 API 키가 있으면 대체 이미지를 생성합니다. 생성된 이미지는 공식 표지가 아니며 화면에 **AI 생성 대체 이미지**로 표시합니다.

이미지 제공처의 통신 오류는 이미지가 없는 경우와 구분합니다. 검색에 실패하면 안내를 표시하고 GPT 생성을 건너뛰며, 다음 조회 때 다시 시도합니다.

- 외부 이미지 검색 중: `이미지 가져오는중...`
- GPT 이미지 생성 중: `gpt로 이미지 생성중...`
- 외부 검색 결과는 10분 동안 캐시합니다.
- 생성 이미지는 현재 사용자 세션에서 재사용하며 파일로 영구 저장하지 않습니다.
- 평점과 추천 결과도 세션에 저장되므로 연결이 새로 만들어지면 초기화될 수 있습니다.

## Git 업로드 시 참고

API 키를 코드·노트북 출력·스크린샷에 포함하지 마세요. 원본 Parquet은 앱이 다운로드하므로 Git에 포함하지 않아도 실행할 수 있습니다. 아래는 **저장소 최상위 `.gitignore`에 넣을 수 있는 예시**입니다.

```gitignore
.env
.env.*
.venv/
__pycache__/
*.py[cod]
.ipynb_checkpoints/
data/
```

노트북과 대체 CSV를 함께 올릴지는 저장소 용도와 데이터 재배포 조건에 맞춰 선택하면 됩니다.

## 자주 발생하는 문제

- **`missing ScriptRunContext` 메시지가 나옵니다:** `python game_taste_analyzer.py` 대신 `python -m streamlit run game_taste_analyzer.py`로 실행하세요.
- **추천 버튼이 비활성화되어 있습니다:** 저장한 평가가 5개 이상인지 확인하세요. API 키는 추천 버튼 활성화의 필수 조건이 아닙니다.
- **표시된 게임 순서가 원본 데이터와 다릅니다:** 로컬 CSV 대체 데이터 사용 경고가 있는지 확인하세요.
- **이미지가 없거나 로딩이 오래 걸립니다:** 외부 서비스의 응답과 네트워크 상태에 영향을 받습니다. GPT 이미지 생성 여부는 로딩 문구로 구분할 수 있습니다.
- **추천이 3개 미만입니다:** 기본 조건을 충족하는 게임이 부족하면 같은 이웃의 다른 게임으로 보충합니다. 이웃 10명이 평가한 미평가 게임 자체가 부족하면 3개를 채울 수 없습니다.
